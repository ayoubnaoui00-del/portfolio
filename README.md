# Ayoub Ennaoui — Developer Portfolio

Personal developer portfolio showcasing Mobile, AI & AR full-stack projects with a dark glassmorphism design system.

## Tech Stack

- **Framework:** Next.js (App Router, TypeScript)
- **Styling:** Tailwind CSS (Custom Dark Glassmorphism Design System)
- **Deployment:** Vercel

## Getting Started

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the portfolio.

## Scripts

- `npm run dev` — Start development server on `localhost:3000`
- `npm run build` — Build for production
- `npm run start` — Start production server
- `npm run lint` — Run ESLint
